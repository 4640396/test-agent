## 实现细节

### 1. impact.ts — 变更影响分析模块

#### getChangedFiles(projectPath, baseRef?)
- `git diff --name-only HEAD` 识别变更文件（默认对比工作区 vs HEAD）
- 支持 `baseRef` 参数（如 `HEAD~1` 对比上次提交）
- 支持环境变量 `TEST_AGENT_GIT_BASE_REF` 自定义基准
- 非 git 仓库 / git 不可用 / 无变更 → 返回空数组（降级全量跑）

#### getChangedLines(projectPath, baseRef?)
- `git diff --unified=0` 解析 hunk header 提取新增行号
- 返回 `ChangedFileLines[]`（每文件的 addedLines 列表）
- `parseDiffForAddedLines(diffText)` 纯函数，可独立测试

#### selectAffectedCases(cases, changedFiles)
- **文件级粗粒度**（方法级依赖图二期不做）
- 用例 target → `extractTargetFile` → 文件路径 → 匹配变更文件集
- **保守策略（不漏跑）**：无 target / 无法映射文件的用例 → 包含（不跳过）
- 无变更文件 → 全量跑（所有用例都受影响）
- PRD 7.5 场景A 验收：选中用例集合 ⊇ 真实受影响集合

#### computeIncrementalCoverage(projectPath, changedLines, affectedCaseCount, totalCaseCount, mode)
- 查找覆盖率报告：istanbul JSON (`coverage/coverage-final.json`) / jacoco XML (`target/site/jacoco/jacoco.xml`)
- 解析行级覆盖数据：
  - istanbul: `statementMap` + `s`（执行次数 > 0 → 覆盖）
  - jacoco: `<line nr="N" ci="M"/>`（ci > 0 → 覆盖）
- 计算交集：变更行 ∩ 覆盖行 → 增量覆盖率百分比
- 无报告/无变更行 → `percentage: null` + `fallbackReason`

### 2. types.ts — 类型扩展

```typescript
export interface IncrementalCoverageResult {
  mode: 'incremental' | 'full';
  changedFiles: string[];
  changedLineCount: number;
  coveredChangedLineCount: number;
  percentage: number | null;
  affectedCaseCount: number;
  totalCaseCount: number;
  fallbackReason?: string;
}
```

- `AgentRunResult.report.incrementalCoverage?: IncrementalCoverageResult`
- `AgentRunContext.fullRun?: boolean` — 全量跑开关

### 3. runner.ts — runExecute 集成

执行前（变更影响分析）：
1. 判断模式：`context.fullRun` 或 `TEST_AGENT_FULL_RUN=true` → 全量；否则增量
2. 增量模式：`getChangedFiles` → `selectAffectedCases` → 筛选 `executionCases`
3. 无变更 → 降级全量跑（所有用例都执行）
4. `buildExecutionPrompt` 只用 `executionCases`（LLM 只看到受影响用例）

执行后（增量覆盖率）：
1. `getChangedLines` 获取变更行号
2. `computeIncrementalCoverage` 计算变更代码行 ∩ 覆盖行
3. 结果写入 `result.report.incrementalCoverage`

Flaky 检测同步更新：
- 历史记录、可疑识别、质量门禁评估均使用 `executionCases`（只记录实际执行的用例）
- 用例库保存仍用完整 `cases`（保存测试计划，非执行结果）

### 4. 全量跑开关

| 开关 | 作用 |
|------|------|
| `AgentRunContext.fullRun = true` | 调用方（worker-mode/hand-mode）强制全量 |
| `process.env.TEST_AGENT_FULL_RUN = "true"` | 环境变量强制全量 |
| `process.env.TEST_AGENT_GIT_BASE_REF` | 自定义 git diff 基准（默认 HEAD） |

## 降级与兜底

| 场景 | 降级策略 |
|------|---------|
| 非 git 仓库 | `getChangedFiles` 返回 [] → 全量跑 |
| 无变更文件 | `selectAffectedCases` 返回全部 → 全量跑 |
| 无覆盖率报告 | `percentage: null` + `fallbackReason`，不阻断 |
| git 不可用 | `spawnSync` 异常 → 返回 [] → 全量跑 |
| 用例无 target | 保守包含（不跳过，不漏跑） |
